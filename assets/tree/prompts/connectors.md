# Shared Eco Machina foliage connectors

Generate `connector-1.png` through `connector-6.png` at **64 x 64
RGBA**. Use a perfectly flat `#ff00ff` chroma-key background, then remove it
to alpha. These six sprites are shared by every tree species.

Base prompt for every texture:

> One very thin angular brown tree twig running from the left edge to the right edge, isolated on a perfectly flat #ff00ff chroma-key background, no leaves and no shadow. Exactly 64x64 pixels, crisp hard pixel-art sprite, no anti-aliasing, text, logo, or watermark.

Append these variant clauses respectively:

- `01`: nearly straight, one tiny upper offshoot.
- `02`: gently upward, one short fork.
- `03`: gently downward, one short fork.
- `04`: subtle S curve, two tiny offshoots.
- `05`: sharp upward fork close to the right end.
- `06`: irregular dry twig, three tiny asymmetric offshoots.
